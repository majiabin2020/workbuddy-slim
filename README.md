# WorkBuddy加速瘦身（workbuddy-slim）

> 一个 WorkBuddy 技能：给你的 WorkBuddy 做"体检 + 瘦身"，专治**越用越慢、执行任务时间长、token/积分消耗大**。

## 为什么需要它

WorkBuddy 用久了变慢，多数情况不是网络问题，也不是模型变笨，而是每一轮对话都背着一堆越来越重的"固定行李"：

- **全局规则文件**越写越多，每轮全文注入，几十 KB 很常见；
- **记忆文件和每日工作日志**只增不减；
- **技能**装了一堆不常用的，每轮都要扫描匹配；
- **连接器（MCP）**装多了，工具说明每轮都注入；
- 一个会话从头干到尾，上下文越滚越大。

这些行李你自己看不见，本技能就是那个"体检医生 + 保洁阿姨"。

## 它做什么

**两段式：先体检（只读零风险），后瘦身（逐项确认）。**

### 第一阶段：体检（只读，不改任何文件）

运行扫描脚本，输出一张红黄绿体检报告，覆盖五项：

| 检查项 | 判定 |
|--------|------|
| ① 全局规则体积 | 单文件 >8KB 黄 / >100KB 红；总量 >40KB 黄 / >120KB 红 |
| ② 记忆与日志 | MEMORY.md 超 3000/4000 字上限；30 天以上旧日志未蒸馏 |
| ③ 已安装技能 | >20 黄 / >40 红 |
| ④ 自定义连接器 | >6 黄；与内置功能重复的单独提示 |
| ⑤ 会话卫生 | 固定习惯提醒（新任务开新会话、长会话压缩） |

报告末尾给总结论：**每轮固定注入的行李估算 X KB，瘦身后预计降到 Y KB**，按收益排序。

```bash
# 直接跑（报告打印到终端）
python3 scripts/slim_scan.py

# 指定工作区并输出文件
python3 scripts/slim_scan.py --workspace /path/to/工作区 --out slim-体检报告.md
```

纯 Python 标准库，无任何第三方依赖，无网络请求，Python 3.9+。

### 第二阶段：瘦身（逐项确认，永不自动删除）

由 AI 助手按 SKILL.md 手册执行，五个动作：

| 动作 | 做什么 | 安全保障 |
|------|--------|----------|
| A. 规则瘦身 | 超重规则移到按需读取区 + 自动写指针文件 | 内容一字不删；先整目录备份 |
| B. 记忆蒸馏 | 30 天以上旧日志蒸馏合并进 MEMORY.md | 原日志归档到 `memory/archive/` |
| C. 技能清理 | 列清单供你勾选禁用 | 只禁用不卸载，随时恢复 |
| D. 连接器精简 | 备份后删除确认不要的 MCP 条目 | 改前 `.bak-日期` 备份 |
| E. 复检 | 重跑体检出前后对比 | — |

## 红线（安全设计）

1. **永不自动删除任何文件**——只有归档/备份移动和用户明确确认的操作；
2. 规则正文一字不改不删，只改"怎么加载"；
3. 不碰聊天记录和个人文件；
4. 每步先备份，做完汇报全部改动路径；
5. 幂等：重复跑不会重复归档、重复建指针；
6. 禁止一键全清，瘦身动作逐项确认。

## 安装

把整个仓库放进 WorkBuddy 技能目录即可：

```bash
git clone https://github.com/majiabin2020/workbuddy-slim.git ~/.workbuddy/skills/workbuddy-slim
```

然后新开会话，说"给我的 WorkBuddy 做个体检"即可触发。

## 已知边界

- 只扫当前工作区的工作区记忆，其他项目需切目录分别体检；
- 软链接规则文件不参与统计、瘦身时跳过（避免破坏 dotfiles/同步工具）；
- 技能计数含已禁用项，结合设置页人工确认；
- 体检报告为磁盘体积估算，确切注入量以官方为准；
- macOS 实测通过；Windows 路径已用 pathlib 写但未验证。
